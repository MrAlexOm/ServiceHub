# ServiceHub - Web Version

Веб-приложение для управления сервисным бизнесом: клининг, услуги мастеров, химчистка и т.п.

## 🚀 Быстрый запуск

1. **Откройте файл `index.html` в браузере**
   - Двойной клик по файлу
   - Или перетащите в окно браузера
   - Или правая кнопка → "Открыть с помощью" → выбрать браузер

2. **Все готово!** Никакой установки не требуется.

## 🤖 Настройка ИИ-ассистента

### Требования для работы чата 'Новый заказ'

Для полноценной работы ИИ-ассистента в чате 'Новый заказ' требуется настройка Gemini API:

1. **Создайте файл `config.js` в корне проекта**
2. **Добавьте в файл следующий код:**
   ```javascript
   var API_KEY = "ВАШ_GEMINI_API_КЛЮЧ";
   ```
3. **Получите API ключ:**
   - Перейдите в [Google AI Studio](https://aistudio.google.com/app/apikey)
   - Создайте новый API ключ для Gemini
   - Скопируйте и вставьте в `config.js`

**Важно:** Файл `config.js` уже добавлен в `.gitignore` и не будет загружен в публичный репозиторий.

### Модель и настройки
- **Модель:** `gemini-1.5-flash`
- **Роль ИИ:** Диспетчер клининга 'CleanTeam' в Анталье
