# ServiceHub - Web Version

Веб-приложение для управления сервисным бизнесом: клининг, услуги мастеров, химчистка и т.п.

## 🚀 Быстрый запуск

1. **Откройте файл `index.html` в браузере**
   - Двойной клик по файлу
   - Или перетащите в окно браузера
   - Или правая кнопка → "Открыть с помощью" → выбрать браузер

2. **Все готово!** Никакой установки не требуется.

## 📱 Функционал

## 🚀 Как использовать

1. Скачайте все файлы в одну папку
2. Откройте `index.html`
3. Выберите роль:
   - **Мастер**: Перейдет на заглушку мастера
   - **Админ**: Откроет экран авторизации
4. Введите email из whitelist и любой пароль
5. Наслаждайтесь работой!
